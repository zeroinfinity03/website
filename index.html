Multi-Agent Research Assistant

GitHub ↗
Problem
Research questions that span several independent sources mean opening each one, reading it separately, and reconciling the answers by hand.
Built
A supervisor on LangGraph that decomposes each request and fans out to specialist agents, each owning one data source and running concurrently. Their results are merged and de-duplicated into a single answer.
Outcome
One grounded, citation-backed report from work that previously had to be reconciled manually.

Applied AI Engineer

Shivoy, Inc · Virginia

I build and run the agent platform behind client GenAI products on AWS.
